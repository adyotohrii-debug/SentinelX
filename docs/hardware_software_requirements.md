# SentinelX — Hardware & Software Requirements

## Hardware Requirements

| Resource | Minimum Requirement | Recommended Requirement |
| :--- | :--- | :--- |
| **Processor** | Dual-core 2.0 GHz | Quad-core 3.0 GHz+ |
| **Memory (RAM)** | 4 GB | 8 GB or higher |
| **Disk Space** | 500 MB free storage | 2 GB free storage |
| **Network** | Broadband internet connection | High-speed low-latency connection |

---

## Software Requirements

| Category | Component | Minimum Version |

| **Operating System** | Windows 10/11, Ubuntu 20.04+, macOS 12+ | Any modern OS |
| **Runtime** | Python | 3.10 or higher |
| **Runtime** | Node.js | 18.0 or higher |
| **Package Manager** | npm / pip | Latest |
| **Optional Tool** | Nmap CLI | 7.90 or higher |
| **Optional Tool** | OWASP ZAP | 2.12 or higher |
| **Web Browser** | Chrome, Firefox, Edge, Safari | Latest evergreen releases |
