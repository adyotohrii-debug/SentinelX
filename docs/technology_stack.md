# SentinelX — Technology Stack

## Core Architecture

### Backend Framework
- **FastAPI**: Asynchronous Python web framework for building high-performance APIs with automatic OpenAPI/Swagger documentation.
- **Uvicorn**: ASGI web server implementation for Python.

### Frontend Framework
- **React 18**: Component-based user interface library.
- **Vite**: Next-generation frontend build tool and dev server.
- **React Router DOM**: Client-side routing management.

### Database & ORM
- **SQLite3**: Lightweight, zero-configuration embedded relational database.
- **SQLAlchemy**: Python SQL toolkit and Object Relational Mapper (ORM).

### PDF & Visualization
- **ReportLab**: Programmatic PDF document generation engine.
- **Recharts**: Composably styled React charting library.
- **Lucide Icons**: Clean, scalable UI icon system.

### Security & Networking Libraries
- **python-whois**: Domain WHOIS metadata parser.
- **dnspython**: DNS toolkit for Python.
- **requests**: Synchronous HTTP library for API communication and security header analysis.
- **Nmap CLI & OWASP ZAP REST API**: External scanner binaries and REST interfaces.
